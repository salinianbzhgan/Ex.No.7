# Aim: To develop a prompt-based application using ChatGPT - To demonstrate how to create a prompt-based application to organize daily tasks, showing the progression from simple to more advanced prompt designs and their corresponding outputs.

# AI Tools Required: 
* ChatGPT / OpenAI API – Core engine for prompt interaction
* Prompt Engineering Techniques
* Role prompting
* Structured prompts
* Parameterized prompts
* Web Browser or Simple Command Line Interface

# Explanation: 
A Prompt-Based Application uses carefully designed prompts to guide a Large Language Model (LLM) like ChatGPT to generate useful responses.

In this experiment, we design a Digital Daily Planner Assistant that can:
* Organize daily activities
* Schedule reminders
* Provide wellness suggestions
* Answer basic questions
* Adapt to user preferences
# Prompt
“Create a smart daily assistant that helps users organize tasks, manage schedules, suggest health tips, and answer simple questions. The assistant should communicate in natural language and personalize responses based on user preferences.”
# Procedure

* Identify the requirements of a digital productivity assistant.
* Design prompts that guide ChatGPT to perform tasks such as scheduling, reminders, and wellness suggestions.
* Simulate interaction through prompts entered into ChatGPT or a command-line interface.
* Observe how different prompt styles change the output.
* Enhance prompts by adding structure, roles, and personalization.
* (Optional) Store preferences to simulate adaptive responses.
# Project Concept
“Smart Daily Planner Assistant”

The assistant will perform the following tasks:
* Organize daily activities
* Manage reminders and schedules
* Suggest healthy habits
* Answer simple productivity questions
* Adapt to user preferences through prompts
# PHASE 1 — Basic Prompt
Prompt

“List a simple plan for my day.”

Example Output

Your Plan for Today:

* 8:30 AM – Check messages and emails
* 10:30 AM – Work on assignments
* 1:00 PM – Lunch break
* 4:00 PM – Review pending tasks
* 7:30 PM – Evening walk

This phase shows a basic prompt with minimal information, producing a simple response.
# PHASE 2 — Structured Prompt
Prompt

“Create a daily schedule for me. I have classes at 9 AM and 2 PM. I need 3 hours for studying, 30 minutes for exercise, and some relaxation time in the evening.”

Example Output
Daily Schedule

* 9:00 – 10:00 AM : Class Session
* 10:30 – 12:00 PM : Study Time
* 12:30 – 1:00 PM : Lunch Break
* 2:00 – 3:00 PM : Afternoon Class
* 4:00 – 5:30 PM : Study / Assignment Work
* 6:00 – 6:30 PM : Exercise
* 8:00 – 9:00 PM : Relaxation / Entertainment
This phase demonstrates how structured inputs improve output quality.
# PHASE 3 — Role Prompt + Output Format
Prompt

“You are my daily planner assistant. Create a schedule based on the following details:

* Classes: 9 AM, 2 PM
* Study Time: 3 hours
* Exercise: 30 minutes

Display the output in a table with columns for Time, Activity, and Notes.”
# PHASE 4 — Advanced Prompt (Personalized)
Prompt

“You are my intelligent productivity assistant. Consider these preferences:

* I enjoy studying in the morning.

* I prefer short breaks after long work sessions.

* Remind me to stretch every 2 hours.

Create a friendly daily schedule including reminders and wellness suggestions.”
# PHASE 5 — Converting Prompts into an Application
System Flow

User Input →
Generate Prompt →
Send Prompt to ChatGPT →
Receive AI Response →
Display Schedule
